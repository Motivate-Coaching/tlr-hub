Brand Foundation
What TLR is, and the principles that guide every design decision.
PrincipleWhat it means in practice
CalmingGenerous white space. No clutter. Nothing competing for attention. The page feels like a breath out.
InspiringBeautiful typography. Thoughtful copy. Each tool should feel worth opening.
ClearOne instruction at a time. Labels that say exactly what they mean. No jargon without explanation.
ImpactfulTools that produce a real output — something the member can keep, act on, and return to.
SatisfyingThe completion moment matters. The dopamine hit of finishing is built into every tool.
Copy RuleDetail
No em dashesNever use — (em dash). Use a comma, colon, or rewrite the sentence.
No unexplained abbreviationsAlways write the full term first: "The Living Room (TLR)" not just "TLR" on first use.
No skipped stepsEvery instruction must be complete. Never assume the user knows what to click next.
Themes, not monthsAlways say "theme" or "topic". Never "month" or "week" in member-facing copy.
Sentence caseTool names use title case. All other copy uses sentence case. Never all-caps for body text.

Spacing System

Tool Anatomy — The Three-Tier System
Every tool is built from three layers. Tiers 1 and 2 are identical across tools. Tier 3 is where each tool earns its own identity.
Tier 1 — The Shell (identical on every tool)
The outer structure that never changes. Members always know where they are and what to do next.
Topbar (back link + TLR logo + theme pill) Cream background #F5F1EB Poppins body font Playfair Display title Auto-expanding textarea inputs Print blank worksheet button Complete this tool button Completion screen structure Momentum actions (Email, WhatsApp, Calendar, Copy) Next topic hint Start again / Back to library
Tier 2 — Theme Identity (one per theme, used across all its tools)
The colour accent that says "you're in this theme." Applied to numbered steps, section highlights, and the completion button.
Theme accent colour (one per theme — see colour system) Theme name in topbar pill Topic number (e.g. "Topic 1 of 4") Next topic hint (links forward to next tool)
Tier 3 — Tool Core (unique to each tool)
The visual metaphor and interaction model that makes this tool memorable and distinct from every other.
Central visual (ladder, compass, loop, chart, columns...) Layout pattern (vertical flow, grid, two-column, radial...) Interaction model (rungs, checkboxes, sliders, circle segments...) Quote or closing statement (tool-specific)

Tone of Voice
The tools are a coach in text form. Every word should feel like Stuart in a session: direct, warm, non-judgemental, and efficient with people's attention.
Do — Placeholders and prompts
"What I most want to move toward…"
"A few words are enough."
"What usually knocks me off course?"
"Moving forward, I want to be more intentional about ___"
Don't
"Please enter your goal here"
"Input required"
"Write your answer in this box"
"N/A"
Do — Instructions
"Choose one. The one that feels most true right now."
"Finish this sentence."
"No ideal version — just what actually happened."
Don't
"Please complete all fields before proceeding."
"Step 1 of 5: Complete the following task."
"This field is mandatory."
Do — Closing quotes and statements
"Momentum isn't built by never stopping. It's built by returning sooner."
"You can't change what you haven't seen clearly."
"Awareness is the first shift. Intention creates the next."
Don't
Generic motivational quotes unrelated to the tool's purpose.
Clichés: "You've got this!", "Believe in yourself!", "Keep hustling!"
Exclamation marks used more than once per tool.
